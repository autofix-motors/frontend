# Confirmación antes de subir cambios

- Nunca ejecutar `git push` (ni `git commit` si implica subir después) sin que el usuario lo confirme explícitamente en el mensaje.
- Antes de subir, mostrar siempre un resumen de qué archivos/cambios se van a subir y a qué rama/repositorio.
- Si el usuario pide "sube esto" sin haber confirmado antes, preguntar primero — no asumir aprobación de un pedido anterior.
- Los mensajes de commit y push no deben mencionar a Claude ni incluir atribución a Claude.
